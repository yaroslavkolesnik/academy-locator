# Academy Locator — фронтенд MVP: дизайн

Дата: 2026-09-17 · Статус: затверджено

## Context
Бекенд готовий (фази 1–4, 171 тест, `smoke.mjs` проходить). Тепер робимо фронтенд для презентації.
Наступні кроки: план реалізації в `docs/plans/2026-09-17-academy-locator-frontend.md` → затвердження →
реалізація по фазах F1–F5, кожна закінчується «Фаза Fn готова, перевірте …».

Рішення користувача: **React + Vite + react-leaflet**; стиль **чистий map-first з кольорами STEAM**;
обсяг — **основний ланцюжок, «Додати заклад», квіз, сторінка модерації /admin**; **mobile і desktop рівноцінно**.

Дані UI/UX Pro Max: `--design-system` запропонував Claymorphism + Baloo 2/Comic Neue — відкинуто
(стиль не пасує інвесторам, Comic Neue не має кирилиці). З бази взято: UX-правила для chips
(`button` + `aria-pressed`, перенос рядків), mobile-first, checklist (SVG-іконки замість emoji, focus, контраст 4.5:1,
reduced-motion, 375/768/1024/1440).

## 1. Архітектура

```
academy-locator/
  web/                        Vite root (React 19, JS + JSX, без TypeScript)
    index.html
    src/
      main.jsx, App.jsx       роутер + MetaProvider
      api/client.js           fetch-обгортка → ApiError(code, message, details)
      api/hooks.js            useApi(url) з AbortController, стани loading/error/data
      state/filters.js        серіалізація фільтрів ↔ URL query (pure)
      map/                    MapView, SteamRingMarker (SVG divIcon), LocationButton
      panels/                 ResultsList, InstitutionCard, DirectionCourses, CourseDetails
      forms/                  RegistrationForm, AddInstitution (PickPoint + форма)
      quiz/                   QuizDialog, QuizResults
      admin/                  AdminPage
      ui/                     Button, Chip, Sheet, Dialog, Field, EmptyState, Skeleton
      styles/tokens.css       дизайн-токени; *.module.css поруч з компонентами
  public/                     ← результат `vite build` (git-ignored)
  vite.config.js              root: web, outDir: ../public, proxy /api → :3000
```

- **Один `package.json`**: додаються `react`, `react-dom`, `react-router-dom`, `leaflet`, `react-leaflet`,
  `lucide-react`, `@fontsource-variable/manrope`, `@fontsource/unbounded`; dev — `vite`, `@vitejs/plugin-react`,
  `vitest`, `jsdom`, `@testing-library/react`.
- **Скрипти**: `dev:web` (Vite :5173 з проксі на API), `build` (`vite build`), `test` →
  `node --test "tests/**/*.test.js"` (явний шлях, щоб не чіпати фронтенд-тести), `test:web` (`vitest run`).
  Фронтенд-тести називаються `*.spec.js(x)`.
- **Шрифти та Leaflet — з npm (self-hosted)**: без CDN, CSP лишається суворою. Зовні лише тайли карти.

### Зміни в бекенді (малі, з тестами)
1. `src/app.js`:
   - **SPA fallback**: `GET` не на `/api/*`, без розширення файлу → `public/index.html` (якщо існує).
     Deep links типу `/institutions/khpi` працюють після перезавантаження.
   - **CSP** у helmet: `img-src 'self' data: https://*.basemaps.cartocdn.com`; решта за замовчуванням.
2. `render.yaml`: `buildCommand: npm ci --include=dev && npm run build`
   (`NODE_ENV=production` інакше пропускає devDependencies → Vite відсутній → збірка падає).
3. `.gitignore`: `/public/`.

## 2. Візуальна система

- **Карта**: CARTO Positron (світла, мінімалістична, не сперечається з кольоровими мітками),
  атрибуція OSM + CARTO обов'язкова.
- **Шрифти**: Unbounded (логотип, заголовки панелей) + Manrope variable (увесь UI). Обидва з кирилицею.
- **Токени** (`tokens.css`):
  - фон `#F8FAFC`, поверхня `#FFFFFF`, текст `#0F172A`, приглушений `#475569`, межа `#E2E8F0`;
  - основний (бренд, CTA) `#2563EB`, hover `#1D4ED8`; успіх `#16A34A`; помилка `#DC2626`; «на модерації» `#B45309`;
  - STEAM-кольори **беруться з `/api/meta`** (S `#16A34A`, T `#2563EB`, E `#EA580C`, A `#DB2777`, M `#7C3AED`) —
    єдине джерело правди; текст на них перевіряється на контраст (для світлих — темний текст);
  - радіуси 12/16/24, тіні м'які двошарові, spacing 4/8/12/16/24/32, базовий шрифт 16px, line-height 1.5.
- **Іконки**: `lucide-react`. Emoji з `quiz.json` не використовуємо — варіанти квізу мапляться на іконки за `id`.
- **Motion**: 150–250 мс ease-out для панелей/шторки, пульс підсвічених міток; усе вимикається при `prefers-reduced-motion`.

## 3. Маршрути та макет

URL = стан (посилання можна відкрити з телефона на презентації). Фільтри живуть у query і зберігаються при переходах.

| Шлях | Панель / вікно |
|---|---|
| `/` | результати: список закладів + лічильник «N закладів · M курсів» |
| `/institutions/:id` | картка закладу |
| `/institutions/:id/:slug` | курси напрямку |
| `/courses/:courseId` | деталі курсу + кнопка «Зареєструватися» (форма в Dialog) |
| `/add` | «Додати заклад»: вибір точки → форма |
| `/quiz` | квіз (Dialog поверх карти) |
| `/admin` | окрема сторінка модерації (без карти) |

Query фільтрів: `q`, `category=T,E`, `age=10-13` (id вікової групи з meta → `ageFrom/ageTo` для API),
`price`, `format`, `type`, `near=1` (використати геолокацію).

**Desktop (≥1024px)**: карта на весь екран; ліва плаваюча панель 400px (пошук, фільтри, вміст маршруту);
вгорі справа — «Підібрати курс» (квіз) і «+ Додати заклад».
**Mobile (<1024px)**: карта на весь екран; зверху — рядок пошуку й кнопка фільтрів; знизу — шторка з трьома
станами (згорнута з лічильником / половина / повна), керування кнопкою-ручкою та свайпом; FAB «+».
Фільтри на mobile — повноекранний Dialog з кнопкою «Показати N».

## 4. Екрани та поведінка

- **Карта**: мітка = SVG-кільце з сегментами STEAM-профілю (`steamProfile`) + ініціали/лічильник збігів у центрі;
  `pending` — пунктирне сіре кільце й бейдж «На модерації»; вибрана мітка збільшена; кнопка «Поруч зі мною»
  (Geolocation API → `lat/lng`, сортування списку за відстанню, синя точка користувача; відмова → toast).
  Мітки клавіатурою не фокусуються — доступна альтернатива це список результатів.
- **Пошук**: підказки з `/api/search/suggest` (≥2 символи, debounce 200 мс), групи «Напрямки / Заклади / Курси»;
  напрямок → додає фільтр, заклад → картка, курс → деталі. Enter → фільтр `q`.
- **Фільтри**: chips STEAM (колір категорії, `aria-pressed`), вік (групи з meta), ціна, формат, тип закладу;
  «Скинути» з кількістю активних; порожній результат → EmptyState з кнопкою «Скинути фільтри».
- **Картка закладу**: назва, тип, адреса, контакти (лише ненульові), кільце профілю, напрямки як плитки з кольором
  категорії й «2 з 3 курсів підходять» (`matchedCourseCount`), напрямки без збігів приглушені. Бейдж «На модерації».
- **Курси напрямку**: картки курсів (вік, формат, ціна, старт, «лишилось N місць» при ≤5), невідповідні фільтрам — приглушені.
- **Курс**: опис, для кого, розклад, тривалість, рівень, ціна; «Зареєструватися» → форма (ім'я, телефон/email,
  вік учасника, коментар, згода). Помилки 400 → під відповідними полями за `details[].path`; 409 → «Місць немає»;
  успіх → екран «Заявку прийнято» + оновлене `seatsLeft`.
- **Додати заклад**: крок 1 — клік по карті ставить перетягувану мітку (поза межами міста — підказка),
  адреса вводиться вручну; крок 2 — форма (назва, тип, адреса, опис, сайт, телефон, email, контактна особа,
  укриття так/ні/не вказано, напрямки chips). Успіх → закриття, фокус карти на новій мітці «На модерації».
- **Квіз**: питання з `/api/quiz` по одному (прогрес 1/5), multi-select для інтересів, «Поруч зі мною» просить
  геолокацію; результат з `POST /api/recommendations`: до 3 карток з причинами + «Показати на карті»
  (застосовує `filters` до URL, підсвічує мітки пульсом). Порожній результат → пропозиція пом'якшити умови.
- **/admin**: поле токена (зберігається в `sessionStorage`), вкладки «Заявки» (approve/reject з підтвердженням
  в інтерфейсі, не `confirm()`) і «Реєстрації» (таблиця на desktop, картки на mobile). 401 → повернення до поля токена.
- **Загальне**: скелетони під час завантаження; помилка мережі → повідомлення з «Спробувати ще»;
  `dataNotice` — ненав'язливий рядок у панелі; холодний старт Render (запит >3 с) → «Прокидаємо сервер…».

## 5. Доступність і якість
Контраст 4.5:1, видимий focus, усі інтерактивні елементи — `button`/`a`, touch-цілі ≥44px, Dialog з фокус-пасткою
та Esc, `aria-live` для лічильника результатів і статусу форм, `lang="uk"`, viewport meta, без горизонтального
скролу на 375px, `prefers-reduced-motion`.
